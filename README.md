## OREO APP
- Interactive Game where you can ask Oreo the Cat what it needs right now
- An easy modular Application with easy to read code structure to use as a CheatSheet
- More advanced concepts of CSS Styling to try out _(jumping Buttons)_

## About the Project
- Another Full Stack Exercise to understand the structure of Web Developing
- A cozy Web Application to play with when you are bored or sad
- Cats are cute to look at and buttons are nice to press

## Features
- Modern Front-End with Card and cozy Font (Poppins)
- REST-API application with Spring-Boot
- Randomizer for the Status of the Kitty

## Requirements
- Text Editor (VS-Code. HTML, CSS, Java Script)
- IDE (I recommend IntelliJ but other will do just fine)
- Gradle (Project was made with gradle)
- JDK 21+
